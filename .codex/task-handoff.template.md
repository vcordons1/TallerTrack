# Handoff de tarea

Este archivo no define un formato propio. En TallerTrack manda `AGENTS.md`:

- **Al terminar un ticket**: el REVIEW_HANDOFF tiene el formato de `AGENTS.md` §12.
- **Si una sesión se interrumpe a mitad de ticket**: lo duradero se guarda en el repositorio y en el vault (`AGENTS.md` §3 y §13). Usa la nota del ticket en el vault (`02-tickets/`) con el estado de la tarea y el siguiente paso exacto. No uses `.codex/task-handoff.md` como fuente de estado.
